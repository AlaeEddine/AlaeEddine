## Déploiement GitHub Pages

### Structure du projet

.
├── index.html              # Page principale (HTML sémantique + JSON-LD)
├── css/
│   └── style.css           # Styles (design system + responsive)
├── js/
│   └── main.js             # i18n (EN/FR/AR), animations, interactions
├── robots.txt              # Directives pour les robots d'indexation
├── sitemap.xml             # Plan du site pour le SEO
└── README.md               # Ce fichier

### Étapes de déploiement

1. Clonez le dépôt :
   git clone https://github.com/AlaeEddine/votre-repo.git
   cd votre-repo

2. Poussez sur GitHub :
   git remote set-url origin https://github.com/votre-utilisateur/votre-repo.git
   git push -u origin main

3. Activez GitHub Pages :
   - Settings → Pages
   - Source : Deploy from a branch
   - Branch : main / dossier : / (root)
   - Save

4. Site accessible à :
   https://votre-utilisateur.github.io/votre-repo/

### Test en local (aucun build requis)

   # Python
   python3 -m http.server 8000

   # Node.js
   npx serve .

   # PHP
   php -S localhost:8000

Puis ouvrez http://localhost:8000
